# 要求一覧

## 全体
- Mac / NixOS / Windows / Ubuntu の4台の Claude Code セッションを1画面で監視・操作したい(全台 同一 Tailscale 上)
- 進捗・要約・どこまで進んでいるか・複数エージェントの概要を把握したい
- 完了時に通知が欲しい。Mac・iPhone両方で使いたい
- メモリ消費は節約したいが、数GB程度なら許容範囲
- 既存ツールで足りるなら既存ツールを使う。フルスクラッチは避ける

## 監視・操作
- 読むだけでなく、その場からリモートでタスクを投入(操作)したい
- 複数セッションを同時に表示したい(一覧+切り替えでは不十分)
- Windows は WSL・ネイティブ両方で動くようにしたい
- 同時セッション数は2〜4本程度
- sudo権限を含む自動化(NixOSの `claude-yolo` 相当)がそのまま使えること

## Mac側
- ターミナルベース、Safari等ブラウザ経由のUIは使いたくない(重い・見づらい)
- 最終的には Tauri のような軽量ネイティブGUIで作りたい
- Mac自身にもネイティブ通知が欲しい(iPhone任せにしない)

## iPhone側
- ネイティブアプリで使いたい

## ccdeck(Tauriアプリ)固有
- 生のターミナル忠実性は不要。チャット型UIでも構わない
- 一画面で複数セッションを同時に見られる(グリッド)
- permission mode / model / reasoning effort を全てUIから切り替えられること(必須)
- 見た目の良さが最優先
- 既存のHappyアカウント/デバイス認証情報をそのまま使う(新規ペアリング不要)
- このリポジトリ(multi-claudemonitor)に同居。将来リポジトリ名は変える可能性あり
- 一覧からそのままセッションを操作できること
